# .github

The default issue and pull request templates and the security policy for every Zvid-in-UA repo.

GitHub serves a template from here to any repo in the org that has none of its own, so a
template lives here once instead of being copied into each repo. A repo that defines its own
`.github/pull_request_template.md`, or any file in its own `.github/ISSUE_TEMPLATE/`, uses only
its own, and none of the defaults of that kind.
