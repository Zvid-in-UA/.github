# Security policy

If you find a vulnerability in Zvid, report it privately through
[a security advisory](https://github.com/Zvid-in-UA/.github/security/advisories/new).
Never open a public issue, pull request or discussion about it.

Say what you found, where, and how to reproduce it. Only the maintainers can read the report,
and we reply in the advisory.

Test only against data you own, and stop as soon as you have shown the problem. Do not degrade
the service for others, and do not access, change or keep anybody else's data.
